爱问云邀请码导出 2.1.2 · macOS 使用说明
========================================

一、先确认 Mac 芯片
点左上角苹果图标 → 关于本机 → 看“芯片”一栏：
- Apple M1 / M2 / M3 / M4：用 aiwenyun-invite-macos-arm64.zip
- Intel Core i5 / i7 / i9：用 aiwenyun-invite-macos-x64.zip
拿不准就先试 arm64；打不开再换 x64。

二、第一次打开（macOS 会拦截）
这个软件没有购买苹果开发者签名，所以第一次打开会被系统拦截，
提示“Apple 无法验证……”。这是正常的，不是病毒。

macOS 15 及以上：
1. 双击 App，出现提示后点“完成”。
2. 打开 系统设置 → 隐私与安全性。
3. 拉到页面底部“安全性”，点“仍要打开”。
4. 输入开机密码，再双击 App，点“打开”。

如果找不到“仍要打开”，打开“终端”，执行：
xattr -dr com.apple.quarantine "/Applications/爱问云邀请码导出.app"
（如果 App 在下载文件夹，把路径换成 ~/Downloads/爱问云邀请码导出.app）

三、使用步骤
1. 先打开爱问云客户端，用老师账号登录，进入主界面。
2. 打开“爱问云邀请码导出”。
3. 第一次会弹窗提示“需要重启爱问云客户端”，点“确定”。
   软件会自动关闭并重新打开爱问云，并在本机 127.0.0.1:9222 开调试端口。
   如果 macOS 弹出“是否允许……”，点“允许”。
   读取登录态后会自动恢复正常窗口；如果爱问云再次重启，是正常现象，稍等即可。
4. 回到导出工具：
   - “从 0 天前开始”一般不用改；
   - “并发”保持 8；
   - 需要明细就勾选“生成明细”。
5. 点绿色“一键导出 Excel”。
6. 等待完成。Excel 保存在：
   桌面 → 爱问云邀请码 → 邀请码-日期时间.xlsx

四、常见问题
1. 提示“登录态验证失败 / CERTIFICATE_VERIFY_FAILED”
   - 确认用的是 2.1.1 版（窗口标题有 2.1.1）。
   - 2.1.1 已内置证书；如果还报错，双击“诊断.command”，
     把生成的“诊断日志.txt”发回来。
     如果双击没反应，打开“终端”执行：
     bash ~/Downloads/诊断.command
     （路径按实际位置改）
2. 提示“找不到爱问云客户端”
   - 确认爱问云客户端在“应用程序”文件夹，名字是 AiCloud.app。
   - 如果不在，拖到“应用程序”再试。
3. 提示“无法打开，因为无法验证开发者”
   - 按上面“第一次打开”的步骤处理。
4. 导出到一半卡住
   - 软件有超时和重试，等它跑完；如果一直不动，关掉重开再试。
5. Excel 打不开或乱码
   - 用 Microsoft Excel 或 WPS 打开，不要用文本编辑器。
6. 爱问云白屏
   - 等待导出结束，程序会自动恢复正常窗口。
   - 如果一直白屏，手动退出爱问云（Cmd+Q）再打开。

五、安全说明
- 只读取本机已登录爱问云客户端的登录态。
- 不读取密码、聊天记录、通讯录。
- 登录 token 只在本机内存使用，不写日志、不写 Excel。
- 只请求爱问云官方 HTTPS 域名。
