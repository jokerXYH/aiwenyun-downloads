爱问云集成工具 v2.3.6 · 使用说明
=====================================

【运行环境】
· Windows 10 / 11（64 位）电脑，双击 exe 就能跑，不用装 Python 或任何组件。
· 需要电脑上装有「爱问云老师端」并已登录（工具只读取它的登录态，不会踢下线）。

【第一次打开】
如果出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
（exe 没有买代码签名证书，Windows 对陌生程序都会这样提示，不是病毒。）
个别杀毒软件会对这种「单文件 exe」误报，添加信任即可。

【三个功能】
1) 邀请码导出
   点「导出邀请码 Excel」，按课程导出实时课堂的邀请码，
   文件保存在桌面「爱问云邀请码」文件夹。

2) 板书导出
   连上爱问云后会自动列出所选时间段的课堂（可筛最近一年 / 最近三年）；
   班级按钮上带学期，例如「26秋7MA+31」「25暑7MAA12」，点按钮切换班级。
   窗口放不下的班收在「更多」里，按学期分组选择。
   勾选要导出的课堂，点「导出所选板书」。
   保存位置自己选，PDF 按「学期+班级」分文件夹，文件名就是课堂名。

3) 反馈文件导出
   自动列出历史课堂和作业，按班级分组、按时间排序；勾选后点
   「导出所选反馈」。同时生成：
   · 课堂权限 CSV：格式与爱问云「历史课堂权限」导出统计报告一致；
   · 作业成绩 CSV：沿用爱问云「作业统计」格式。
   两类文件都按班级分文件夹保存。

【小提示】
· 三个功能页都可以用 Ctrl+1 / Ctrl+2 / Ctrl+3 切换。
· 导出或列清单时右下角会弹出进度卡片，显示百分比、当前节/页、已用和
  剩余时间；完成、取消或失败后都会自动消失，也可以点「关闭」。
· 工具只读操作：不提交、不批改、不改动任何反馈或课堂数据。
